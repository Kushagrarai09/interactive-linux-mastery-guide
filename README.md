# 🐧 Interactive Linux Mastery Guide

Learn Linux from scratch through an interactive, beginner-friendly learning experience covering Linux fundamentals, terminal commands, shell scripting, filesystem concepts, Docker, DevOps, and practical exercises.

## 🚀 Live Website

👉 **[Open the Interactive Linux Mastery Guide](https://kushagrarai09.github.io/interactive-linux-mastery-guide/)**

Explore the hosted learning guide directly in your browser.

## ✨ What You'll Learn

- **Linux Fundamentals** — Understand Linux and its core concepts.
- **Terminal Commands** — Practice essential command-line workflows.
- **Filesystem** — Learn paths, files, directories, and filesystem structure.
- **Permissions** — Understand users, groups, and access permissions.
- **Shell Scripting** — Explore command automation and scripting basics.
- **Docker & DevOps** — Build a foundation for modern development and deployment workflows.
- **Practical Learning** — Reinforce concepts through examples and exercises.

## 🎯 Who Is This For?

- Beginners starting their Linux journey
- Developers who want to improve their command-line skills
- Students preparing for software, backend, cloud, or DevOps roles
- Anyone who prefers structured, interactive learning

## 🧭 How to Use

1. Visit the [live learning website](https://kushagrarai09.github.io/interactive-linux-mastery-guide/).
2. Follow the topics in order, starting with the fundamentals.
3. Try the examples and exercises as you progress.
4. Revisit commands and concepts whenever you need a quick refresher.
